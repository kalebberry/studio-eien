### The Premise

When working with modern AI coding tools, it is easy to slip into autopilot. The suggestions appear instantaneously, tests pass, and features get checked off, but the deeper mental work—understanding why an edge case broke or how a layout actually reflows—can quietly fade into the background.

**Kangae (考え)**—derived from the Japanese word meaning *thought*, *thinking*, or *an idea*—is a personal developer learning workflow built around the philosophy: **"Think with AI, not through AI."**

### A Workflow, Not an Application

Kangae is not a standalone AI application, a specialized browser extension, or an autocomplete replacement. It is a portable set of vendor-neutral Markdown instructions and reusable workflow skills (`.kangae/`) dropped directly into a project repository. It provides structured collaboration guidelines that encourage AI assistants to offer small, progressive nudges rather than immediately replacing the developer's reasoning.
