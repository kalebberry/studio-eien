<EditorialSection
	eyebrow='APPROACH // 02'
	title='Dual-Engine Mechanics: Grid Meets Boundary-Free Flex'
	lead='A single layout paradigm cannot solve all editorial demands. True craftsmanship requires choosing the exact physical tool for the spatial plane.'
	layout='asymmetric'
	signature='SECTION: MECHANICS ⟡ METHOD SIGNATURE: V.03'
>
	<p>
		Rather than forcing all content into a singular rigid pattern, Kōshi introduces a
		dual-engine layout model built directly into Studio Eien’s CSS compositions:
	</p>
	<ul>
		<li>
			<strong>Two-Dimensional CSS Grid (<code>.kos-grid</code>):</strong> Governs macro-composition,
			explicit column allocations (1 to 12), subgrid row alignments, and dense layout flows.
		</li>
		<li>
			<strong>Boundary-Free Flexbox (<code>.kos-flex-grid</code>):</strong> Replicates fluid editorial
			broadsheets. Elements claim proportional &ldquo;shares&rdquo; of horizontal space via
			mathematical <code>flex-basis</code> calculations, adapting seamlessly as screen widths shift
			without requiring a fixed column scaffold.
		</li>
	</ul>
	<p>
		By anchoring layout constraints to <code>container-type: inline-size</code> instead of viewport
		media queries, cards and editorial modules adapt to their immediate parent container. An
		editorial component behaves with panoramic grandeur in a main feature column, yet
		instantly and gracefully refolds into a compact index item when positioned in a sidebar.
	</p>
</EditorialSection>
